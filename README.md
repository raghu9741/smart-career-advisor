# Smart Career Advisor

A Flask backend with a static HTML/CSS/JavaScript frontend for career guidance, student registration, admin control, and job and career recommendations.

## Deployment URLs

- Frontend URL: use the real URL generated by your Vercel project after deployment
- Backend health check: `https://<your-render-service>.onrender.com/health`

Do not open `https://your-live-url.vercel.app` directly. That is only a placeholder example and will show `DEPLOYMENT_NOT_FOUND`.

## Project structure

- `backend/` - Flask backend, API routes, database models, and migrations
- `smart-career-advisor/smart-c-advisor/` - static frontend files
- `Dockerfile` - production container image build
- `start.sh` - startup script for Docker and Gunicorn
- `vercel.json` - Vercel static frontend deployment configuration
- `.github/workflows/deploy.yml` - GitHub Actions build and deploy workflow

## Run locally

### Docker

```bash
docker build -t smart-career-advisor .
docker run -p 8000:10000 smart-career-advisor
```

Then open:

- `http://localhost:8000`
- `http://localhost:8000/health`

### Without Docker

1. Create and activate a Python virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Set environment variables:

```bash
set SCA_DATABASE_URI=sqlite:///backend/career_advisor.db
set SCA_ADMIN_USERNAME=admin
set SCA_ADMIN_PASSWORD=admin123
```

4. Run the app:

```bash
python backend/app.py
```

5. Open `http://localhost:5000`

## Deployment notes

- For Vercel, deploy this repository with `vercel.json` kept in the project root.
- The frontend is served from `smart-career-advisor/smart-c-advisor`.
- For Render, use the provided `Dockerfile` or `render.yaml`.
- Set `SCA_DATABASE_URI` to a production Postgres URL in Render.
- The startup script runs database migrations automatically before Gunicorn starts.

## Troubleshooting deployment

- `404: DEPLOYMENT_NOT_FOUND` on Vercel means you are opening a placeholder URL, a deleted deployment URL, or a project that has not been deployed yet. Redeploy on Vercel and use the exact domain shown in the Vercel dashboard.
- `Not Found` on the Render root URL usually means the backend is running without the frontend files. Check `https://<your-render-service>.onrender.com/health` first.
- If `/health` returns `{"status":"ok"}`, the backend is healthy. Deploy the frontend separately to Vercel, or make sure Render is building from the full repository with the included `Dockerfile`.
- If the frontend files are missing in a backend-only deployment, `/` now returns a JSON message explaining that the backend is healthy and the frontend still needs to be deployed.

## Environment variables

- `SCA_DATABASE_URI` - database connection string
- `SCA_ADMIN_USERNAME` - seeded admin username
- `SCA_ADMIN_PASSWORD` - seeded admin password
- `RAPIDAPI_KEY` - API key for live job search
- `RAPIDAPI_HOST` - API host for live job search

## Verify after deployment

- Open your real Vercel URL and confirm the homepage loads.
- Open `https://<your-render-service>.onrender.com/health` and confirm it returns `{"status":"ok"}`.
